Deployment

Two containers on one host in the LAN, one relay on a public host, and Claude cloud sessions started on demand.

Ports

PortWhereUse
4180Host 127.0.0.1 and LAN addressBoard API and web view over HTTP
4443Host 127.0.0.1 and LAN addressBoard web view over HTTPS (local certificate authority). Browsers need it for the web view's crypto functions on the LAN.
4780127.0.0.1 inside the shared networkOrchestrator status, read by the board's operations page
8790Relay host, behind its TLS proxyRelay

The web view has no login: a visitor of these ports acts as the board owner. Use them only on a trusted network; never forward them on the router. vb serve refuses host names other than those given with --allow-host.
